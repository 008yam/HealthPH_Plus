HEALTHPH+ CEBUANO TRANSLATION HANDOUT
Prepared: October 13, 2026
Scope: 407 phrases/templates from the existing inventory, plus 12 normalized keys.
This is a DRAFT catalog for review, not an automatic translation service.
Application source files have NOT been edited.
This does not certify that every current or future string is covered.

WHY SOME LABELS REMAIN ENGLISH
1. A dictionary key must exactly match the English source, including case.
2. The widget must call context.tr(...).
3. Dynamic sentences need templates and parameters, not an already interpolated string.
4. Service errors and server content do not automatically pass through translation.
5. Text baked into image assets cannot be changed by this dictionary.

KEEP THESE VALUES STABLE
- HealthPH+, personal/place names, URLs, IDs, credentials and language names.
- API keys, enum values, stored symptom names, database fields, survey answer values.
- Render translated labels, but submit the original underlying values.
- Account, Profile, Password, Email, PIN, PDF, CSV, AQI, AURI, COVID, MongoDB,
  and familiar borrowed terms can remain recognizable English terms.
- Clinical names without an approved local equivalent remain unchanged.
- Have Cebuano speakers review the whole draft; have qualified reviewers check
  clinical wording and disclaimers. This catalog is not medically validated.
- Backend article bodies/titles, alert messages, authored survey questions, and
  user-entered text are excluded from automatic lookup.
- Some inventory entries are old hardcoded examples. Their dates are translated
  as examples, not made current.
- Existing misspelled English source keys are preserved for compatibility;
  corrected alternatives are included for selected typos. Fixing English source
  independently requires updating the lookup key as well.
- Inventory line references below date from October 5; search by phrase if shifted.

STEP 3 - CONNECT ALL USER INTERFACE TEXT
Import for files directly inside lib/:
  import 'localization/app_translations.dart';
Import for lib/pages/ or lib/widgets/:
  import '../localization/app_translations.dart';

For a literal label:
  BEFORE: const Text("Continue")
  AFTER:  Text(context.tr("Continue"))

For a text field:
  BEFORE: decoration: const InputDecoration(labelText: "Email")
  AFTER:  decoration: InputDecoration(labelText: context.tr("Email"))

For validation:
  BEFORE: return "Enter your email";
  AFTER:  return context.tr("Enter your email");

For tooltips and tab labels:
  tooltip: context.tr("View Details")
  Tab(text: context.tr("Articles"))

Remove const only from the containing runtime widget/list/decoration when it
contains context.tr(...). Fixed styles/icons can remain const.
Do not run a global replacement over every String or every title/subtitle.
Data keys, server values, and user input are not translation keys.

STEP 5 - DYNAMIC TEMPLATES: IMPORTANT
Inventory placeholders such as {reports.length} are literal dictionary keys,
not Dart expressions evaluated by translateText().

Do not do this:
  context.tr('Your Recent Reports (${reports.length})')

Use this exact inventory key and parameter name:
  context.tr(
    'Your Recent Reports ({reports.length})',
    parameters: {'reports.length': reports.length},
  )

Or use one of the added normalized templates:
  context.tr('{count} reports', parameters: {'count': reports.length})

For PIN email:
  context.tr(
    'Enter the six-digit PIN for {widget.profile.email}.',
    parameters: {'widget.profile.email': widget.profile.email},
  )

For nested labels, translate only the local label before inserting it.
Never translate user-provided values.
Preserve all braces/placeholders when changing the dictionary.
If you rename a placeholder, change both dictionary languages and the caller.
Do not convert API request values to Cebuano just because their display changed.
