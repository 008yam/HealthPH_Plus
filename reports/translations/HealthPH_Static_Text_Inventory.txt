Source language: English
Translation languages: Filipino, Cebuano, Ilocano, Hiligaynon

HOW TO USE
- Translate complete phrases, rather than isolated words. Keep each entry ID.
- Preserve placeholders inside braces, such as {duration} and {reportCount}.
- Whitespace and line breaks are collapsed for this reference list.
- Existing spelling/capitalization is preserved so the phrase can be found in code.
- Repeated exact phrases appear once, with all collected source locations.
- Source line numbers refer to this snapshot and may shift after later edits.
- Brand names, geographic names/codes, URLs, assets, database keys, and numeric-only values are excluded.
- Language names are listed as they appear; choose whether to display their native names.
- Medical labels and acronyms (AQI, AURI, COVID, PIN, CSV, PDF) need terminology review.
- Hardcoded example reports are included where they can appear in page widgets.
- Copy/backup pages and the unused Flutter counter demo are excluded.
- Service error text is included for review; some errors are wrapped or replaced by page messages.
- This inventory covers Dart text. Text embedded in images needs separate artwork review.
- Server-provided article bodies, alert messages, survey questions/options, and user input are not static UI text and are not included.
- No translations have been guessed or applied to the application.
